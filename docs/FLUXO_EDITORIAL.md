## Modelo de página editorial

```text
Categoria
  → notícia principal [imagem + manchete + resumo + ler mais]
  → notícias recentes [ordem por publicação]
  → abrir matéria [título, data, editoria, imagem e corpo]
  → retornar à categoria ou continuar lendo
```

## Atualização de conteúdo

```text
Publicação de notícia aprovada
  → validação de data e editoria
  → atualização de categoria
  → atualização da seção da home conforme regra de destaque
  → disponibilização de link para notícia completa
```

## Pendências
- Integrar conteúdo externo apenas após validação da fonte, licença e links.
- Revisar responsividade e funcionalidade dos links.
- Submeter prévia final para aprovação antes de publicação.
